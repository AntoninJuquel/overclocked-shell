# Stories

One Markdown file per story. The folder is the status: `backlog/` → `doing/` → `done/` (move the file with `git mv`).

File name: `S-NNN-short-slug.md`. Template:

```markdown
# S-NNN — Title

**Epic:** E# Name · **Plan:** docs/plans/<plan>.md (once written)

## Why
What the player gets and why it matters.

## Acceptance criteria
- [ ] Observable, testable outcome
```
