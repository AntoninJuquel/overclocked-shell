# Builds (E4, part 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shell designs, optimizes and equips builds like dim-agent — build sheets (json + md view) checked against the game rules, the optimizer with stat and tuning mods, the equip plan and its flow through Shell's write tools — story S-014, with the same optimizer results as dim-agent on the same inventory.

**Architecture:** Port, don't rewrite. dim-agent's `scripts/build/` becomes the package `shell/engines/builds/` (logic unchanged; imports, paths, language and manifest access change); the sheet's Markdown view moves to `shell/outputs/build_md.py`. The manifest data dim-agent downloaded itself (set definitions, mod energy costs, subclass plug index) becomes one compact *build catalog* cached per manifest version next to the defs index. Each dim-agent CLI becomes an MCP tool in `shell/mcp/tools/builds.py`; tools read the inventory snapshot `profile/inventory/*.json` that `refresh_inventory` writes, and the sheets in `profile/builds/`.

**Tech Stack:** Python 3.12, `shell.core` (Manifest, paths), `shell.engines` (defs, inventory rows), `shell.sources` (aegis, compendium, wishlists), `mcp` 2.3 via `shell.mcp.tool`.

**Spec:** `docs/specs/2026-10-28-overclocked-shell-design.md`. Behaviour reference (parity, read-only): `D:\Projects\dim-agent\scripts\build\*.py`, `scripts\common.py`, `tests\test_build_*.py`, `docs\game-rules.md`, skills `.claude\skills\{create-build,optimize-build,equip-build}\SKILL.md`, the player's sheets in `builds\`.

## Global Constraints

- Everything English: SheetError and problem / warning messages, the sheet `.md` labels, tool output, skills. Translate faithfully; do not change rules. Message prefixes the skills key on ("subclass: …", "artifact: …", free-energy and no-tuning-data warnings) are translated together with the skills.
- Sheet data values: `resolved.armor[].masterwork` becomes `"todo"` / `"done"` (was `"à faire"` / `"fait"`). `sheet.migrate(s) -> dict` maps the old values; `sheet.load` applies it, so French sheets keep loading (S-017 imports them as they are).
- Compendium markdown is English now: attribute lines are `- key: value` (split on the first `": "`), `colonne` is `column`.
- Paths: sheets `profile/builds/<slug>.json` + `.md`; inventory `profile/inventory/armor.json` / `weapons.json`; triage grades `profile/triage/weapons.json` (`items[].grade`); farm needs `profile/todo/needs.json` + `state.json` (dim-agent format; absent until S-015 → no "To fetch" section). Catalog cache `cache/defs/builds-s<SCHEMA>-<version>.json`.
- No core edits. New code in `shell/engines/builds/`, `shell/outputs/`, `shell/mcp/tools/`, `.claude/skills/`, `tests/`.
- Writes to the account go through the existing tools with their dry-run defaults; nothing in this plan posts to Bungie itself.
- itemIds stay strings everywhere (the optimizer's tie-break compares them as strings).

## Rulings in this plan (player can override)

1. **One build catalog** (`sets`, `costs`, `subclass` index) cached per manifest version instead of dim-agent's per-script downloads of the full item table. Same data, built by the same functions.
2. **Tools replace scripts**, one per CLI: `check_build`, `optimize_build`, `subclass_options`, `artifact_options`, `rankings`, `weapon_candidates`, `equip_plan`. Exit codes become fields (`ready`, `feasible`, `complete`, `problems`).
3. **Inventory comes from the snapshot file**, so skills call `refresh_inventory` first (as they called `export_armor`), and every tool result names the snapshot time.
4. **No `get_item` tool.** `get_equipped` already returns the subclass and artifact instance ids; the only remaining use of `get_item` (fragment sockets shown as disabled when the catalog does not know them) becomes a warning that asks the player to check in game.

## Review Focus

1. **A sheet the player edited by hand is invalid or stale** (unknown stat, two exotics, resolved items no longer in the inventory) → one-line `SheetError` / plan `problems`, nothing written, nothing equipped. (Tasks 3, 6)
2. **The snapshot is older than the player's last game session** → tool results carry the snapshot time; skills refresh first; an equip plan built on a moved item reports it instead of equipping the wrong thing. (Tasks 4, 6)
3. **Optimizer search hits its 200 000-evaluation limit** → `complete: false` in the result and the skill tells the player the result may not be optimal; `write` refuses an infeasible result unless `force`. (Task 4)
4. **A French sheet from dim-agent** (`"à faire"`, French `rationale` text) loads, renders and optimizes; only `masterwork` values are migrated, free text is left as written. (Task 3)
5. **The catalog cache is from an older manifest** → rebuilt when the version changes, like the defs index. (Task 1)
